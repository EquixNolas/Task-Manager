# Análisis
  
  ### Administrador del proyecto
  >Es el encargado de administrar el proyecto, titulo, tareas, fechas de entrega y sobre todo usuarios.
  Puede:
  * Gestionar Usuarios.
  * Gestionar Proyectos.
  * Gestionar Tareas.
  * Cancelar / Eliminar el proyecto.
  * Consultar estado de progreso del proyecto.
  * Eliminar Usuarios.
